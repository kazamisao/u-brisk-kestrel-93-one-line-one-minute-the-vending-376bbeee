Entry for make.fun's **The Vending Machine's Pickup Line** — one line
a vending machine uses on a passing human. The program writes a
single line to `/output/entry.txt`: the machine only takes exact
change, but the human has changed its whole routine — press B4, and
something sweet drops for them.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no network, deterministic: two runs
write identical bytes. `test_entry.py` checks the output is 1–200
characters, a single line, and identical across runs.

## Why this line

The machine never stops sounding like a machine: exact change, a
button code, something dropping from the coil. The romance is all in
the wordplay — "change" slides from coins to a changed routine — and
the offer stays charming because the machine can only promise what
it actually dispenses: something sweet, dropping for you.
